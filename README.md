# 📚 Library Management System

A simple console-based Library Management System developed using Java. This application allows administrators to manage books and users to view, issue, and return books efficiently.

## 📌 Features

### Admin Module

* Secure Admin Login
* Add New Books
* View Available Books
* Delete Books
* Manage Library Records

### User Module

* View Available Books
* Issue Books
* Return Books
* Check Book Availability

## 🛠 Technologies Used

* Java
* ArrayList
* Scanner Class
* Object-Oriented Programming (OOP)

## 🚀 How to Run

### Compile the Program

```bash
javac LibraryManagementSystem.java
```

### Run the Program

```bash
java LibraryManagementSystem
```
